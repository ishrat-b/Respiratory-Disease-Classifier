# Results

Results are retained by experiment. Metrics and figures should be interpreted together with the notebook, dataset split, preprocessing branch, and model configuration that produced them.

This repository does not publish one overall final accuracy. The historical notebooks contain validation/test reports, confusion matrices, ROC plots, and training figures, but they are not all attributable to the same pipeline or checkpoint.

The `figures/` and `metrics/` directories are reserved for results that can be traced clearly to a documented experiment. No unverified result has been promoted here.
